## voom events

Stream VM and forward change events

```
voom events [flags]
```

### Options

```
      --filter stringArray   filter events by type, event, vm, or id
  -h, --help                 help for events
      --since string         show events since a timestamp, duration, or event ID
      --until string         stream until a timestamp or duration
```

### Options inherited from parent commands

```
      --output string   output format: text or json (default "text")
  -v, --verbose         enable verbose diagnostics
```
